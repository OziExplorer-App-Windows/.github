## Overview
OziExplorer for Windows is a dedicated mapping and GPS navigation tool built for people who need to work from a specific map rather than a generic online one — a scanned topo sheet, nautical chart, or property survey, for example. Once that image is calibrated against known coordinates, OziExplorer keeps waypoints, routes, and GPS tracks organized around it, so trip planning and in-field navigation happen in the same workspace.

## Features
- [ ] Calibrate scanned or digital map images against real-world coordinates
- [ ] Track live GPS position, heading, and speed on the calibrated map
- [ ] Create, edit, and reuse waypoints and routes
- [ ] Log GPS tracks for later review or repeat trips
- [ ] Support a wide range of map projections and coordinate datums

## FAQ
- [ ] **Is OziExplorer free?** — It can be evaluated for free, with a paid registration that unlocks the full version.
- [ ] **Can I use free maps with OziExplorer?** — Yes, many people calibrate OziExplorer maps sourced from freely available scanned charts and public map archives, alongside any maps they already own.
- [ ] **Does OziExplorer work without an internet connection?** — Yes, once a map is calibrated and saved locally, navigation and track logging don't require an internet connection.

- [ ] **License:** OziExplorer is shareware — a free evaluation version is available, and a paid registration unlocks the full application.
